# AR-Prompt3D

Extended Reality 2025-2026 — Supplemental Project (Topic 2)

An AR web application that lets a user speak or type a description of an
object and see it appear, freshly generated by an AI 3D-generation model, in
their real physical space.

Project scaffold in progress — see `docs/report/` for the write-up and
`public/` for the client application once implemented.
